# StockSense-Odoo
Real-time Odoo-based Inventory Management System for managing products, warehouses, receipts, deliveries, internal transfers, stock adjustments, low-stock alerts, and a centralized stock ledger. Built for the Odoo × LPU Jalandhar Hackathon 2026.

## Frontend
This repository contains the sleek, utilitarian React dashboard for managing inventory.

## Backend / Authentication
This branch also includes the integrated backend authentication module.
